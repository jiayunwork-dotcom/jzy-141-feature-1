# 连锁便利店周销量 Holt–Winters 预测与回测平台

面向补货计划员的内部网页工具：上传/选择周销量序列 → 后台拟合 Holt–Winters
（加法/乘法季节，趋势可选「无 / 加法 / 加法阻尼」）→ 页面查看拟合曲线、
未来若干周点预测与预测区间 → 滚动原点回测并与**季节朴素法**对照。
数值内核（递推、优化、区间、回测）全部手写，仅依赖 NumPy，**不调用**
statsmodels 等现成实现。

- 后端：Python 3.12 + FastAPI + SQLAlchemy + PostgreSQL 16
- 前端：React 18 + Vite + TypeScript + Recharts
- 后台任务：有界线程池（`app/jobs.py`），多计划员处理不同序列互不阻塞
- 编排：`docker compose` 三服务（db / backend / frontend(nginx:1.27-alpine)）

## 一键启动

```bash
docker compose up --build
# 浏览器打开 http://localhost:8080
```

首次启动后端会等待数据库就绪并自动建表。示例数据：
`sample_beverage_sales.csv`（164 周、带夏季高峰与节假日峰值）。

## 页面说明

1. **序列列表**：上传 CSV（两列：周起始日期、销量）。日期按 7 天步长
   校验；缺周会列出具体日期并在序列上打标记；非整周对齐（间隔不是 7 的
   整数倍）直接阻止导入并提示原因。
2. **拟合页**：
   - 原始值、拟合值、未来点预测与置信带同图展示；
   - 参数面板可勾选**锁定 α/β/γ/φ** 中任意若干个（手填数值），其余照常
     自动优化，点击后立即在后台重算；
   - 展示参数、SSE、AIC、残差（标准差等）、最终状态；
   - 自动选型时列出全部 6 种组合的 AIC/SSE/参数/可行性（评分卡），
     最优组合标星；
   - 同一序列的每次拟合都入库，可在底部列表中单选比较。
3. **回测页**：设置首个原点、步长 h、原点步长、置信水平与区间方法；
   逐原点列出 MAE/MAPE/MASE，并与季节朴素法并排，表格汇总 + 单原点
   逐步对照。页面所有数字均由后端计算。
4. **门店—区域—全网页**：新建树（自带全网根节点）与区域，把现有序列
   选/挂进区域（挂接被拒时立即显示是哪家店、周期还是起止周对不上）；
   对整棵树发起层级预测，逐节点查看历史、基础预测、调和后预测与两者之
   差；引用旧拟合/旧结构的结果醒目标「已过期」并给出原因，可一键重算或
   走局部重算；层级回测按层对照调和前/后的 MAE、MASE。

所有计算在后台任务中执行，页面显示进度条与阶段；任务结果（拟合/回测）
落 PostgreSQL，可重复查看与比较。

## 模型定义（与代码一一对应）

记水平 `l_t`、趋势 `b_t`、季节指数 `s_t`，季节周期为 `m`（周数据默认 52）。

**加法季节**

```
ŷ_t = l_{t-1} + φ b_{t-1} + s_{t-m}
l_t = α (y_t - s_{t-m}) + (1-α)(l_{t-1} + φ b_{t-1})
b_t = β (l_t - l_{t-1}) + (1-β) φ b_{t-1}
s_t = γ (y_t - l_t) + (1-γ) s_{t-m}
```

**乘法季节**（加法式同上改为比值：`ŷ_t=(l_{t-1}+φb_{t-1})s_{t-m}`，
`l_t=α y_t/s_{t-m}+(1-α)(l_{t-1}+φb_{t-1})`，
`s_t=γ y_t/l_t+(1-γ)s_{t-m}`）。

`φ=1` 对应无阻尼；趋势选「无」时没有 `b` 与 `β`。

候选组合共 6 种：趋势 ∈ {无, 加法, 加法阻尼} × 季节 ∈ {加法, 乘法}。

### 参数取值区间（优化约束）

| 参数 | 含义 | 区间 |
|---|---|---|
| α | 水平平滑 | [0.001, 0.999] |
| β | 趋势平滑 | [0.001, α] |
| γ | 季节平滑 | [0.001, 0.999] |
| φ | 阻尼 | [0.80, 0.98] |

目标：最小化**样本内一步预测误差平方和**（SSE），且 SSE 只统计从第
`2m+1` 个观测开始的真正「样本外一步」误差（前两个完整季节用于初值）。
优化器是手写的多起点 Nelder-Mead，在 logit 变换后的无约束空间搜索并以
确定性起点网格运行，因此**同一输入重复拟合结果一致**。锁定的参数从搜索
向量中移除，只优化剩余参数。

### 初始分量（前两个完整季节，文档化的固定规则）

设第 1、2 个季节的均值为 `L0、L1`：

- 初始趋势 `b = (L1 - L0)/m`；
- 初始水平（位于第 `2m-1` 期末）`l = L1 + (m-1)/2 · b`；
- 加法季节初值 `s_i = y_i - (L0 + (i-(m-1)/2)b)`（i=0..m-1），再中心化
  使 `Σ s_i = 0`；
- 乘法季节初值 `s_i = y_i / (L0 + (i-(m-1)/2)b)`，再归一化使
  `mean(s_i)=1`；
- 无趋势时令 `b=0`、基准线为 `L0/L1`。

归一约定在拟合后始终保持（加法季节和为 0、乘法季节均值为 1），
最终状态的季节槽按「槽 0 对应未来第 1 步」规范化。

### SSE 与 AIC

高斯一步误差下：

```
AIC = n·(ln(2π) + ln(SSE/n) + 1) + 2(k+1)
```

`n` 为贡献 SSE 的观测数，`k` 为被估计的平滑参数个数
（无趋势：α,γ=2；有趋势：α,β,γ=3；阻尼再加 φ=4），`+1` 为误差方差。
自动选型取可行组合中 AIC 最小者。

### 预测与区间

点预测由最终状态直接递推（阻尼用
`b·φ(1-φ^h)/(1-φ)` 累积趋势）。区间两种做法，可在页面选择：

1. **解析近似（默认）**：线性误差状态空间（Gardner 等价误差形式
   `l_t=l_{t-1}+φb_{t-1}+αe_t`、`b_t=φb_{t-1}+αβe_t`）下 h 步预测误差
   方差为 `σ²·Σ_{i=1..h} ψ_i²`，其中

   ```
   ψ_1 = 1
   ψ_h = α + αβ·(φ+φ²+…+φ^{h-1}) + γ(1-α)·𝟙{(h-1) 是 m 的整数倍}   (h≥2)
   ```

   φ=1 时括号内即 h−1；无趋势时去掉 β 项。季节冲击
   `s_t = … + γ(1-α)e_t` 恰好在 m 步后被消费，因此 γ 项每过一个完整季节
   出现一次。该闭式系数已用残差自助模拟数值校准（偏差仅模拟噪声量级）。
   加法模型用绝对残差估计 σ；乘法模型用相对残差 `e_t/ŷ_t`，
   区间为 `ŷ_h(1 ± z·se_h)`。
2. **模拟**：对残差（乘法时为相对残差）做有放回自助抽样，从最终状态
   正向传播 2000 条路径，取经验分位数。

两种方法都**强制半宽随步长单调不减**（累积最大值）——这是预测误差方差
正确累积应有的性质，也可消除自助抽样噪声导致的局部回缩；乘法区间下限
截断在 0。

### 拒绝规则（返回明确原因）

- 乘法季节要求序列全为正：出现 0 或负值 → 拒绝；
- 少于 `2m` 个观测 → 拒绝（无法估计初始分量）；
- 递推中水平/乘法季节指数变为非正 → 该组合标记失败并记录原因；
- 自动选型不会静默丢弃不可行组合，评分卡里带原因列出。

## 回测定义

给定起点 `origin_start`、步长 `h`、原点步长 `stride`：

- 对每个原点 `k`，**只用 `y[:k]`** 重新初值化、重新优化参数、重新拟合，
  再预测未来 h 步；
- **季节朴素基准**：`ŷ_{k+j} = y_{k+j-m}`（照抄上一季节）；
- 指标：
  - MAE = 平均绝对误差；
  - MAPE = 平均绝对百分比误差（实际为 0 的点跳过）；
  - MASE 尺度 `Q = mean_{t=m..k-1}|y_t - y_{t-m}|`（每个原点按其训练段
    重算），MASE = mean|e|/Q；
- 汇总在全部原点/步长上池化计算，逐原点指标也一并给出。

测试用「原点之后注入极端值、预测不变」证明第 k 个原点不使用未来数据。

## 层级预测（门店—区域—全网）

在**不改动任何单序列能力**的前提下，把已有序列组织成一棵最多三层的树：

```
全网（level 0，根；历史不允许上传）
 ├─ 区域甲（level 1；历史 = 下级逐周加总）
 │   ├─ 门店一（level 2，叶子 = 一条已上传的周序列）
 │   └─ 门店二
 └─ 区域乙
     └─ 门店三
```

- 区域/全网**没有独立数据入口**：其历史在每次读取时由门店叶子逐周加总。
- 挂接校验与作业用的是**同一个校验器**（`hierarchy/tree.py`）。门店叶子
  必须周期相同、起始周相同、截止周相同（隐含周数相同）；不满足时挂接被
  拒绝，消息点名是哪一个子节点、差在哪里，例如
  「子节点『门店二』周期 12 与已挂接的『门店一』（周期 52）不一致」。
  一个序列在一棵树里只能挂一次；聚合节点不允许关联上传序列。
- 树上允许先建空区域再挂门店（页面工作流）；此时树 `valid=true` 但
  `ready_for_forecast=false`，预测按钮禁用并给出原因。

### 一次层级预测里发生了什么

1. **版本快照（并发安全）**：任务在一个数据库事务里读齐树结构（含
   `structure_revision`）、各叶子序列、以及每个叶子**当前最新的 Fit 行
   id**，并把拟合用到的列拷贝成脱离 session 的快照。随后整棵树的基础预测
   全部基于这组快照完成，最后一个事务一次性写结果。因此：
   - 任务执行期间另一位计划员给某家店重拟，只会**新增一行 Fit**；旧任务
     结果里记录的 `fit_refs` 必然就是它真正用到的那组 Fit，不可能前几个
     节点用旧拟合、后几个用新拟合；
   - 这次结果会立刻被标为**已过期**（见下），但数字自洽。
2. **每个节点一份基础预测**：
   - 门店叶子：取该店最新一次单序列拟合（任意趋势/季节/锁参组合都可以），
     从其最终状态递推点预测；这样叶子的基础预测与单序列页**完全相同**，
     挂进层级不会改变任何单序列数字。区间按本次请求的置信水平/方法从该次
     拟合的残差重新生成。
   - 区域/全网：对逐周加总后的历史，用本次指定的趋势/季节组合现场拟合
     同一个手写 Holt–Winters 内核。
3. **调和（reconciliation）** 与一致性检查；
4. 整份结果（每个节点的历史、基础预测、调和后预测、两者之差、引用的 Fit
   id）连同 `structure_revision`、`fit_refs` 一次写入 PostgreSQL；任何节点
   拟合失败都会报出节点名与原因，**不写半成品**。

### 调和方法：为什么选自底向上（bottom-up, BU）

调和后的点预测 = 叶子保留各自的基础预测，每个父节点等于其直接下级之和，
逐层向上。实现见 `kernels/reconcile.py`。

- 天然精确满足「任意父节点每个预测日期 = 直接下级之和」，三层同时成立
  （测试以相对容差 1e-6 固定，实际为机器精度）；
- 叶子数字一个都不改 → 不侵犯单序列结果；
- 只有一个下级的区域（区域乙）调和后与那家店**逐日期完全相同**；
- 在基础预测本就一致的场景（同一加性模型、无噪声加总）调和前后差异在
  数值噪声级别（参考算例 ≤ 0.01，实际 ~1e-13）。

**放弃了什么**：没有采用自上而下（会牺牲门店信息）和 WLS/MinT 最小迹调和
（统计上可能更准，但调和后的每个节点都是**所有**基础预测的线性组合——一
家店重拟会牵动全树，无法做到只改一条路径）。选 BU 换的是可审计的加法，
以及下面这条重算性质。

**局部重算 vs 整棵重算**：叶子没变的门店直接复用上一次结果里的基础列（
fit id 一致为前提），变更门店重新取数；所有聚合点预测只依赖加总历史（未
变）且拟合确定性，故重新拟合得到与整棵重算相同的数；调和是自底向上加法，
只有「变更叶子 → 其祖先」这一条路径可能变化。两条路径的点预测与区间逐日期
一致（测试容差 **1e-9**）。树结构在上次之后变过则拒绝局部重算。

### 调和后的预测区间

区间**随调和一起给出**，叶子区间即单序列区间；父节点采用**保守（同单调）
宽度和**：父半宽 = Σ 直接下级半宽。这是任意相关结构下的并集上界（不估计
跨店误差相关——那正是 MinT 被放弃的信息），且每个下级的半宽都随步长单调
不减，所以和也单调不减：调和后区间宽度仍对 h 单调不减（测试固定）。叶子
/聚合各自的**基础**区间也保留展示，两组不必相等；以调和后这组作为层级口径。

### 可追溯与过期

每次层级预测落库 `fit_refs = {门店节点 id: 使用的 Fit id}` 与
`structure_revision`。结果在以下任一情况发生时标 `stale=true` 并在页面上
醒目标红、给出原因，不再作为最新数字：

- 树结构发生增删（`structure_revision` 前进）；
- 任意门店有了更新的 Fit（最新 Fit id ≠ 引用 id，含锁参重拟）。

页面可对过期结果**一键重算**；同一棵树的多次层级预测/回测都保留，可互相比
较。

### 层级回测

对整棵树按滚动原点回测（`hierarchy/backtest.py`）：每个原点 k **只使用截至
k 的数据**——叶子取前缀，区域/全网在前缀上重新加总，每个节点重新初值化、
重新优化拟合并预测 h 步，再做与在线完全相同的自底向上调和。输出**按层
（全网/区域/门店）与逐节点**的调和前/调和后 MAE、MASE，直观看出调和帮了
哪一层、伤了哪一层。原点隔离用「在原点之后注入极端值，该原点每个节点的
基础与调和预测都不变」证明（容差 1e-8）。

### 参考算例（后端测试固定）

三家店均从 2022-01-03（周一）起 164 个点、无噪声，t=0 为首周：

- 店一 `100+0.2t`，每 52 周第 48 周再 +50；
- 店二 `150+0.3t`，第 20 周再 +30；
- 店三 `80+0.1t`，第 48 周 +20、第 20 周 +10。

店一、店二挂区域甲，店三单独挂区域乙，两区域挂全网。加法趋势 + 加法季节、
预测 12 步时：各节点基础预测本身已一致，调和前后逐节点逐日期差 ≤ 0.01；
**全网第一步点预测 = 428.4**；区域乙调和后与店三逐日期相同。
